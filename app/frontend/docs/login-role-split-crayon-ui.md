# 智汇就业 · 登录与角色分流系统设计（Crayon UI 版）

## 一、设计目标

面向 40-60 岁采摘工用户，建立低学习成本、低操作成本、情绪友好的登录与分流体验，并同时支持：

- 员工端（采摘工）
- 企业端（老板/用工方）

---

## 二、核心设计理念

### 2.1 UI 风格（全局统一）

`Crayon-style mobile employment app`

- 暖色调：米色、浅棕、橄榄绿、橙黄
- 手绘边框（轻微不规则）
- 纸张纹理背景
- 插画元素：水果、篮子、叶子
- 反馈元素：印章、星星、成长植物

### 2.2 交互原则

- 一屏一个核心动作，降低阅读压力
- 点击区域放大，避免误触
- 所有状态反馈可视化（颜色 + 图形 + 文字）
- 操作结果可预期，尽量减少跳转层级

## 三、登录流程重构

### 3.1 流程结构

```text
启动 App
  ↓
角色选择页（新增）
  ↓
登录页（按角色进入不同页面）
  ↓
进入对应端首页
```

### 3.2 页面路由建议

```js
// 角色选择页
if (role === 'worker') {
  wx.navigateTo({ url: '/pages/login/worker' })
}

if (role === 'boss') {
  wx.navigateTo({ url: '/pages/login/boss' })
}
```

## 四、角色选择页（新增核心页）

### 4.1 页面目标

让用户在 1 秒内完成身份判断：

- 我是来找工作的
- 我是来招人的

### 4.2 布局结构

```text
[ Logo 插画 ]

选择您的身份

[ 👷 我是员工 ]
（采摘工找工作）

[ 🏢 我是老板 ]
（发布岗位招人）
```

### 4.3 视觉规范

- 员工卡片：绿色系 + 农民/水果篮插画
- 老板卡片：橙色系 + 农场/仓库插画
- 卡片阴影统一采用柔和投影，强化可点击感

### 4.4 交互反馈

- 点击卡片：`scale(0.96)` + 阴影收缩 + 轻微震动
- 首次进入：卡片错峰淡入（100ms 间隔）

## 五、员工登录页（在现有页面基础上升级）

### 5.1 布局结构

```text
Logo

欢迎回来 🌾

[ 手机号输入 ]
[ 身份证后 6 位 ]

[ 进入智汇就业 ]

注册入口
```

### 5.2 视觉与动效

- 背景：米色纸张纹理 + 顶部绿色到米色渐变
- 输入框 focus：边框转绿色 + 轻微发光
- 登录按钮点击：缩放 + 阴影变化
- 登录成功：页面淡入切换

### 5.3 登录成功跳转

```js
wx.switchTab({
  url: '/pages/index/index'
})
```

## 七、企业信息填写页

### 7.1 表单结构

```text
企业名称
营业执照上传 📷
工作环境图片 📷
工作地址 📍
工资标准 💰
```

### 7.2 设计细节

- 卡片式表单 + 手绘边框
- 上传区域视觉风格为“贴照片”
- 提交时展示 loading + 叶子旋转动画

### 7.3 建议数据结构

```json
{

  "description": "",
```

## 八、审核系统（管理员）

### 8.1 状态定义

| 状态 | 含义 |
| --- | --- |
| pending | 待审核 |
| approved | 已通过 |
| rejected | 已拒绝 |

### 8.2 状态机逻辑

```js
if (adminApprove) {
  status = 'approved'
} else {
  status = 'rejected'
}
```

## 九、二维码页面重构（上工打卡凭证）

### 9.1 页面定位

不是“仅展示二维码”，而是“每日上工凭证”。

### 9.2 页面结构

```text
用户信息卡

[ 🎫 今日上工码 ]
（票据样式卡片）

二维码（居中）

状态提示：
✅ 今日未签到
```

### 9.3 创意映射

- 二维码 = 印章
- 扫码 = 盖章
- 完成签到 = 星星奖励

### 9.4 动效

- 点击生成：卡片展开 → 二维码渐显 → 轻微旋转

## 十、成长体系（全局反馈层）

### 10.1 视觉表达

- 工作天数：🌱 发芽进度
- 收入累计：🍎 水果篮丰满度
- 签到行为：⭐ 星星贴纸

### 10.2 产品价值

- 让重复劳动可被看见
- 提供可持续的正向反馈
- 降低中老年用户的“我不会用”心理压力
