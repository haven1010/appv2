# 如何进行真机验证

1. 打开微信开发者工具当中的**真机调试**，手机微信扫码

2. 打开登录页，点击 **“网络设置”**

3. 填写你电脑当前可被手机访问的地址  
   格式：`http://你的电脑局域网IP:3001/api`  
   ⚠️ 注意：**不是** `127.0.0.1`  

   > 查看当前局域网 IP 的方法：  
   > ```bash
   > ipconfig getifaddr en0
   > ```

4. 点击 **“保存接口地址”**

5. 再次扫码登录测试

---

## 若仍失败，请优先检查：

- 手机和电脑是否连接**同一个 Wi-Fi**
- 后端是否监听 `0.0.0.0:3001`
- 系统防火墙是否放行 `3001` 端口
