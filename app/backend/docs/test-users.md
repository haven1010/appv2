# 测试用户清单

## 固定流程（换电脑直接跑）

为避免出现“小程序登录用户未找到（phone\_hash 漂移）”，本仓库提供固定流程：

1. 进入后端目录执行修复：

```bash
npm run login:baseline
```

2. 只做校验不改数据：

```bash
npm run login:baseline:check
```

3. 修复后固定账号登录口径：

- 账号：`13800000001` ~ `13800000011`
- 密码：身份证后 6 位，即 `010001` ~ `010011`

这条命令可以重复执行，幂等且安全，适合作为每台新机器的初始化步骤。
