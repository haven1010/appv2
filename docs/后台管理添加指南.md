# 后台管理添加指南

## 政策管理（CloudBase 数据库）

### 数据存储位置

政策数据存储在微信 CloudBase 的 `policies` 集合（collection）中。小程序通过云函数 `phase1Api` 读写该集合。

### 政策数据结构

每个 policy 文档的字段说明：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 政策标题 |
| category | string | 是 | 分类：就业补贴 / 培训补贴 / 创业扶持 / 社保政策 |
| publishDate | string | 是 | 发布日期，格式：YYYY-MM-DD |
| department | string | 是 | 发布部门，如"渭南市人力资源和社会保障局" |
| summary | string | 是 | 政策摘要（1-2句话） |
| content | string | 是 | 政策详细内容 |
| requirements | string | 是 | 申请条件（换行用 \n） |
| applyMethod | string | 是 | 申请方式 |
| isDeleted | boolean | 否 | 软删除标记，默认 false |

### 方式一：CloudBase 控制台直接添加（推荐，无需写代码）

1. 打开 [微信云开发控制台](https://console.cloud.tencent.com/tcb)
2. 选择环境 `cloud1-7gukagm3a064dc47`
3. 左侧菜单 → **数据库** → 点击 **添加集合**
4. 集合名称输入 `policies`，点击确定
5. 点击 `policies` 集合 → **添加记录**
6. 按上方表格填入字段和值（JSON 格式）
7. 点击保存

**示例记录（JSON）：**

```json
{
  "title": "就业困难人员社保补贴政策",
  "category": "就业补贴",
  "publishDate": "2026-04-01",
  "department": "渭南市人力资源和社会保障局",
  "summary": "对符合条件的就业困难人员给予社会保险补贴，补贴标准为实际缴纳社会保险费的60%",
  "content": "为帮助就业困难人员实现稳定就业，对符合条件的就业困难人员给予社会保险补贴。补贴标准为实际缴纳社会保险费的60%，补贴期限最长不超过3年。",
  "requirements": "1. 持有就业创业证或就业失业登记证\n2. 属于就业困难人员范围\n3. 已实现灵活就业并缴纳社会保险费",
  "applyMethod": "携带相关材料到户籍所在地或常住地街道乡镇人力资源社会保障服务中心申请",
  "isDeleted": false
}
```

### 方式二：通过 Web 管理后台添加（后续开发）

> 当前 Web 管理后台（`apps/web-admin`）连接的是 NestJS 后端 + MySQL。政策数据的 CloudBase 管理页面待后续开发。

计划中的管理功能页面路由：`/policies`

功能规划：
- 政策列表页：展示所有政策，支持搜索和分类筛选
- 新增政策：表单填写所有字段
- 编辑政策：修改已有政策内容
- 删除政策：软删除（设置 isDeleted = true）
- 发布/下架：控制政策在前端的显隐

## 培训课程管理（CloudBase 数据库）

### 数据存储位置

培训课程数据存储在 CloudBase 的 `trainingCourses` 集合中。小程序通过云函数 `phase1Api` 读写该集合。

### 培训课程数据结构

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 课程标题 |
| category | string | 是 | 分类：采摘技能 / 安全培训 / 职业素养 |
| duration | string | 是 | 课程时长，如"2小时" |
| instructor | string | 是 | 讲师姓名 |
| location | string | 是 | 上课地点，如"线上培训" |
| startTime | string | 是 | 开课时间，格式：YYYY-MM-DD HH:mm |
| description | string | 是 | 课程描述 |
| status | number | 是 | 0=未开始, 1=进行中 |
| isDeleted | boolean | 否 | 软删除标记，默认 false |

### CloudBase 控制台操作步骤

**添加课程列表和详情：**

1. 打开 [微信云开发控制台](https://console.cloud.tencent.com/tcb)
2. 选择环境 `cloud1-7gukagm3a064dc47`
3. 左侧菜单 → **数据库** → 点击 **添加集合**
4. 集合名称输入 `trainingCourses`，点击确定
5. 点击 `trainingCourses` 集合 → **添加记录**
6. 按上方表格填入字段和值（JSON 格式），参考下方示例
7. 点击保存

> **提示：** 一次可添加多条记录。课程详情由 `listTrainingCourses` 接口返回全部字段，`getTrainingCourseDetail` 接口会额外查询用户的报名状态（从 `trainingEnrollments` 集合）。

**学员报名记录：**

学员报名存储在 `trainingEnrollments` 集合中，无需手动管理，系统自动写入：

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | number | 用户ID |
| courseId | number | 课程ID |
| createdAt | string | 报名时间 |
| updatedAt | string | 更新时间 |

## 用户管理与身份审查

### 数据存储位置

用户数据存储在 CloudBase 的 `users` 集合中。所有用户（含管理员、审查员）统一通过该集合管理。

### 添加用户

1. 微信云开发控制台 → 数据库 → `users` 集合
2. 点击 **添加记录**
3. 填入用户信息（JSON 格式），参考下方字段表

### 用户数据结构

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| openid | string | 是 | 微信 openid（用户唯一标识） |
| name | string | 是 | 真实姓名 |
| phone | string | 是 | 手机号 |
| role | string | 是 | 角色，见下方角色表 |
| idCard | string | 否 | 身份证号 |
| infoAuditStatus | number | 否 | 信息审核状态：0=待审, 1=通过, 2=拒绝 |
| realNameVerified | boolean | 否 | 是否已实名认证 |
| isDeleted | boolean | 否 | 软删除标记，默认 false |

### 角色类型（role 字段）

| 值 | 说明 | 审查权限范围 |
|------|------|------|
| worker | 工人 | 无审查权限 |
| boss | 老板 | 可审查自己基地的报名和工资 |
| base_manager | 基地管理员 | 审查基地内岗位、报名、工资草稿 |
| field_manager | 现场管理员 | 现场扫码签到、审查出勤记录 |
| super_admin | 超级管理员 | 全部审查权限：审核注册/变更、查看所有数据、导出报表 |

### 如何以指定身份进行审查

**场景说明：** 不同角色登录小程序后，看到的页面和可操作的功能不同。以审查员身份登录需要确保用户在 CloudBase `users` 集合中已配置正确的 `role`。

**操作步骤：**

1. 确定要使用的审查身份（如 `super_admin` 或 `base_manager`）
2. 在 CloudBase 控制台 → `users` 集合中，找到对应用户记录
3. 确认或修改 `role` 字段为目标角色
4. 确认 `infoAuditStatus` 字段为 `1`（审核通过），否则登录后可能被拦截
5. 在小程序中重新登录（清除缓存后重新授权），系统会从 `users` 集合读取角色信息

**各角色审查功能对照表：**

| 审查功能 | super_admin | base_manager | field_manager | boss |
|------|:---:|:---:|:---:|:---:|
| 审核基地注册/变更 | ✓ | ✗ | ✗ | ✗ |
| 审核工人实名信息 | ✓ | ✓ | ✗ | ✗ |
| 审核岗位报名 | ✓ | ✓ | ✗ | ✗ |
| 生成/审查薪资草稿 | ✓ | ✓ | ✗ | ✗ |
| 审查出勤记录 | ✓ | ✓ | ✓ | ✗ |
| 扫码签到操作 | ✗ | ✗ | ✓ | ✗ |
| 提交薪资报表 | ✗ | ✗ | ✗ | ✓ |
| 导出薪资/出勤报表 | ✓ | ✗ | ✗ | ✗ |
| 查看用户列表/日志 | ✓ | ✗ | ✗ | ✗ |

**快速添加测试审查员（JSON）：**

```json
{
  "openid": "oXXXX-审查员的微信openid",
  "name": "李审查",
  "phone": "13800000003",
  "role": "super_admin",
  "infoAuditStatus": 1,
  "realNameVerified": true,
  "isDeleted": false
}
```

> **注意：** `openid` 需要通过微信登录获取。可以在小程序开发者工具中先微信登录，从云函数日志中查看返回的 openid，再到数据库中更新对应记录的角色字段。

### 批量导入用户

CloudBase 控制台支持 JSON/CSV 批量导入：

1. 进入 `users` 集合 → 点击 **导入**
2. 选择 JSON 或 CSV 文件
3. 每条记录需包含 `openid`、`name`、`phone`、`role` 字段
4. 确认导入

## 常用操作速查

### CloudBase 控制台入口

- 腾讯云控制台：https://console.cloud.tencent.com/tcb
- 环境 ID：`cloud1-7gukagm3a064dc47`

### 数据库操作

| 操作 | 路径 |
|------|------|
| 查看所有集合 | 数据库 → 集合列表 |
| 添加记录 | 进入集合 → 添加记录 |
| 编辑记录 | 点击记录 → 编辑 → 保存 |
| 删除记录 | 点击记录 → 删除 |
| 导入数据 | 集合 → 导入（支持 JSON/CSV） |
| 导出数据 | 集合 → 导出 |

### 权限设置

CloudBase 数据库默认权限为"仅创建者可读写"。对于 `policies` 等公共数据集合，建议修改权限：

1. 数据库 → 选择集合 → **权限设置**
2. 设置为：**所有用户可读，仅管理员可写**
3. 保存
