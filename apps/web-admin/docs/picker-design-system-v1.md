# 采摘工管理系统 Design System（v1.0）

## 1. 设计原则

1. 可信（Trustworthy）
- 优先表达数据真实性：工资、出勤、结算状态。
- 使用蓝色建立可靠感与系统感。

2. 高效（Efficient）
- 关键路径控制在 2 步内（报名、签到）。
- 信息优先级：钱 > 状态 > 其他。

3. 易用（Accessible）
- 面向低数字化用户。
- 大按钮、强对比、少干扰。

### 2.2 字体

- Title：18-20px / Medium
- Body：14-16px / Regular
- Caption：12px / Regular
- Number（重点数值）：20-24px / Semibold

规则：金额必须放大展示，标题不超过 2 行。

### 2.3 间距、圆角、阴影

- Spacing：4 / 8 / 12 / 16 / 20 / 24 / 32
- 卡片内边距：16
- 模块间距：20-24
- Radius：8 / 12 / 16
- Shadow：0 2px 8px rgba(0,0,0,0.05)

## 3. 布局系统

移动端统一结构：

1. 顶部导航
2. 内容区（滚动）
3. 底部 Tab

卡片统一结构：标题 / 内容 / 操作区。

规则：单屏 2-4 张卡，信息分组清晰。

## 4. 核心组件规范

1. Button
- Primary：`#2F6BFF`，白字，12px 圆角，44px 高。
- CTA（赚钱/报名）：黄色渐变（#FFD84D -> #FFC72C）。
- Secondary：白底 + `#E5E7EB` 边框。

2. Card
- 白底、12px 圆角、16px 内边距。

3. Tag
- 进行中：蓝
- 成功：绿
- 未开始：灰
- 警告：橙

4. List
- 结构：[图标] 标题 / 副信息 / >

5. TabBar
- 结构：广场 | AI助手 | ●二维码 | 我的
- 中间按钮：60x60，圆形，黄色渐变。

## 5. 数据可视化

推荐组件：

1. 收入趋势（折线图）
2. 出勤统计（柱状图）

规则：简洁、少装饰、无强网格线，主色使用蓝 + 黄。

## 6. 页面级 Pattern

1. 首页（Dashboard）
- 用户卡片
- 核心数据 3 列：工作天数 / 待结算工资 / 出勤率
- 快捷入口 4 宫格
- 推荐岗位列表
- 系统提示

原则：工资信息最显眼。

2. 报名页
- 进度状态区
- 岗位卡片列表：基地 / 工资 / 时间 / 状态 Tag

3. 二维码页（核心）
- 岗位信息
- 大二维码（占屏约 60%）
- 签到状态
- 刷新按钮

4. 我的页
- 用户卡
- 累计收入（重点）
- 成长体系（徽章）
- 功能列表

## 7. 交互与可用性

1. 点击反馈
- 按钮点击：opacity 0.9
- 卡片点击：轻微阴影变化

2. 状态反馈
- 成功：Toast + 绿色
- 失败：红色提示
- 加载：Skeleton

3. 无障碍
- 最小点击区域：44px
- 文本对比度：>= 4.5
- 重要信息必须颜色 + 文本双表达

## 9. 作品集表达建议

可直接使用的项目总结：

本项目采用蓝黄配色体系构建可信且高效的用工平台体验，通过卡片化布局与数据优先策略，强化“工资与出勤”核心信息展示，并结合二维码签到等高频场景优化交互路径，实现从招聘到结算的完整闭环体验。
